# Plano: alterar link do site para www.ImperialSilverPratas.com

## Objetivo
Deixar o site acessível pelo domínio próprio `www.ImperialSilverPratas.com`, mantendo o conteúdo atual (Imperial Silver).

## O que será feito
1. **Verificar publicação atual** — confirmar se o projeto já está publicado e em qual URL.
2. **Publicar/republicar o projeto** — garantir que a versão atual esteja no ar, com o slug do Lovable ajustado se necessário.
3. **Preparar para domínio customizado** — orientar/guia para conectar `www.ImperialSilverPratas.com` assim que o domínio estiver registrado.

## Limitações
- Não consigo comprar ou registrar o domínio por você. Você pode:
  - Comprar diretamente no Lovable (Project Settings → Domains → Buy new domain) — disponível em planos pagos.
  - Comprar em um registrador externo (Registro.br, Hostinger, GoDaddy, etc.) e depois apontar o DNS para o Lovable.
- A conexão final do domínio é feita na interface de domínios do projeto, mas eu guio os passos.

## Próximos passos após aprovação
1. Eu verifico o estado atual de publicação e publico/republico.
2. Eu informo os registros DNS necessários (A e TXT) assim que o Lovable gerar.
3. Você registra o domínio e configura os DNS conforme orientação.
4. Aguardamos a propagação (até 72h) e confirmamos se `www.ImperialSilverPratas.com` está no ar.

## Observação
Enquanto o domínio próprio não está ativo, o site continuará funcionando no URL `*.lovable.app` padrão.
